# Aceternity UI component sources

Public source retrieved on 2026-10-03. This interface uses a neutral, content-first adaptation of these Aceternity UI components:

- [Resizable Navbar](https://ui.aceternity.com/components/resizable-navbar): official React component; adapted width, border, branding and mobile navigation.
- [Card Hover Effect](https://ui.aceternity.com/components/card-hover-effect): shared hover surface; accessible work buttons replace demo links.
- [Tabs](https://ui.aceternity.com/components/tabs): selected pill animation, category counts and filtering.
- [Animated Modal](https://ui.aceternity.com/components/animated-modal): reduced spring entrance combined with native dialog focus, Escape and a sticky close control.

Spotlight and Hover Border Gradient were removed from the active interface during the content-first redesign. Search, metadata and typography use the neutral surfaces of the component demos.

No paid templates or Pro assets are used. Component authors retain their rights; this project's MIT license covers original gallery logic, not third-party component code. See [Aceternity licence](https://ui.aceternity.com/licence).
