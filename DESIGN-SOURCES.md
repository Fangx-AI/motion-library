# Aceternity UI design sources

All interface design references for this version come from https://ui.aceternity.com/ . Public component registry source retrieved on 2026-10-03.

- Resizable Navbar: https://ui.aceternity.com/components/resizable-navbar — official React component; adjusted desktop width and mobile radius; site branding and links supplied at call site.
- Spotlight: https://ui.aceternity.com/components/spotlight — official SVG component and entrance animation; adapted fill and dimensions.
- Card Hover Effect: https://ui.aceternity.com/components/card-hover-effect — shared animated hover surface and layered rounded cards; gallery images and accessible buttons replace demo links.
- Tabs: https://ui.aceternity.com/components/tabs — selected pill layout animation; category counts and filtered content replace stacked demo content.
- Animated Modal: https://ui.aceternity.com/components/animated-modal — spring entrance and overlay styling; native dialog retains keyboard focus and Escape behavior.
- Hover Border Gradient: https://ui.aceternity.com/components/hover-border-gradient — official moving-border button; used for load more and reset.
- Search/input surface, select, checkbox, footer, and typography follow the neutral dark styles used in the above official demos, adapted for this gallery.
