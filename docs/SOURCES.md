# 资料标记与统计

本站沿用 [上游固定版本](../SOURCE.md)的作者与来源记录，并按资料实际可得程度展示入口。编目记录与本站界面不替代作者原帖。

## 三种指令状态

| 状态 | 含义 | 是否计入 52 条作者提示词正文 |
| :--- | :--- | :--- |
| 作者原文 | 取得作者公开指令文本；也可能只保留其来源入口 | 仅 `prompt.status = original` 且 `prompt.text` 非空时计入 |
| 任务描述 | 作者或编目对目标、效果、过程的说明，不能当成逐字指令 | 否 |
| 未取得指令 | 没有可供展示的指令文本，保留作品与原帖资料 | 否 |

中文译文是辅助阅读；本站和上游的编辑建议与作者原文分开呈现。原文可能是规格或模板，并不意味着完整素材、对话和修改过程均已公开。

## 当前快照

2026-10-05 核验的本站数据共 463 件作品，其中 52 条有作者原文正文、76 条有任务描述正文、19 条有中文译文；25 件作品附源码入口。译文与指令状态可能重叠，不能相加作为作品总数。

本轮新增 22 件效果参考，公开完整提示词正文均未取得；任务转述与来源链接不计入正文。上游共 464 件，其中 1 件未上线候选因原帖已删除而暂缓收录，详见 [本轮来源记录](../SOURCE.md)。

25 件附源码作品按 `resources` 中是否存在 `kind = code` 统计；同一作品多个源码链接只计一件。交互演示、公开网页和制作指南不自动算作源码，源码公开也不等于采用开源许可。

Clearwater 的短句是创作过程描述，不是完整指令。它的演示、源码与上游编辑建议分别提供入口，保持不同资料的归属。

## 排列与可用性

选编与排列服务于浏览，不表示统一质量评级。热度字段来自原帖收藏数据快照，不是实时指标。模型与制作过程按作者说明记录，本站未独立重跑全部作品。

媒体和外链可随原站状态变化。播放失败时可访问作者原帖；资料错误或失效请提交 [本站 Issue](https://github.com/Fangx-AI/motion-library/issues/new)，注明作品链接与问题。
